# Security scope

This repository provides educational examples and read-only artifact validation. It does not provide a sandbox, production authentication, a complete prompt-injection defense or verified enforcement of prose policies.

Inspect code and project-specific commands before running them. The checker reads artifacts but never executes the ledger's verification string. The booking lab uses temporary local SQLite databases and no external services.

Do not post secrets, exploit payloads targeting live systems or private data in public issues. For a vulnerability, use GitHub's private **Report a vulnerability** option if the owner has enabled it. If that option is unavailable, open a minimal issue requesting a private reporting channel without sensitive details. No response-time commitment is established yet.
