# Code of conduct

This project is about honest evidence. The same standard applies to how we treat each other.

## What we expect

- **Critique the work, not the person.** "This check cannot fail" is useful; anything about the author is not.
- **Show, don't assert.** Back claims with a command, a file or an observation, and say plainly when something is a guess.
- **Assume good intent, and ask when unsure.** Many contributors write in a second or third language.
- **Credit sources and other people's work.** Link what you used.
- **Keep it safe to be wrong.** Reporting a failure in the kit, including your own mistake, is a contribution.

## What is not acceptable

- Harassment, insults, or demeaning comments about anyone's identity, background, language or experience.
- Sexual language or imagery, threats, or encouraging harm.
- Publishing someone's private information, or secrets, credentials or patient or customer data, in any form.
- Sustained disruption of discussions, or repeated off-topic promotion.

## Scope

This applies in issues, pull requests, discussions and any other project space, and when someone represents the project elsewhere.

## Reporting and enforcement

Report a concern privately to the maintainer through GitHub (the profile of [@sakti1977](https://github.com/sakti1977)), or through a private security advisory if it involves exposed data. Reports are handled confidentially. The maintainer may edit or remove content, warn, or block participation, in proportion to the harm and whether it recurs. The person reported is told what rule was broken, except when doing so would put someone at risk.

This code is written for this project and draws on the aims of the widely used [Contributor Covenant](https://www.contributor-covenant.org/).
