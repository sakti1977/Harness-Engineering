# Five Layers of a Harness

## Core idea and problem
A longer prompt cannot substitute for execution controls.

## How it works
Reach = map; Power = tools and authority; Ground = ready environment; Verdict = evidence; Carry = durable state. Ablate one layer at a time to see which failure reappears.

## Example / failure mode
The test runner is Power, its assertion is Verdict. A README is Reach only if discoverable and authoritative.

## Implementation and verification notes
Models may improve; retest and simplify scaffolding, but preserve controls with real consequences.
