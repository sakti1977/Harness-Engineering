# Harness Engineering Obsidian Vault

Open this folder as a vault and begin with [[Harness Engineering - MOC]]. Choose a route in [[Learning Path]] or run [[First Executable Harness Lab]].

This collection connects concepts, primary sources, synthetic failures, practical exercises and reusable templates. Reach, Power, Ground, Verdict and Carry are its organizing synthesis. Earlier shared-material attribution remains in [[Source Coverage Index]]; new source-backed material is catalogued in [[Source Register]].

## Runnable learning

Python 3.10+ is enough for the included local lab:

```sh
cd Labs
python3 -m examples.booking.demo
```

No model credentials or package installation are required. The deliberately broken variant must fail two outcome checks before the fixed variant passes. See [[Vault Update Record]] for verification and limitations.

## Public companion

[Harness-Engineering on GitHub](https://github.com/sakti1977/Harness-Engineering) provides the validator, tests, templates and the generated GitHub handbook. The learning content is maintained in its `vault/` directory; `docs/handbook/` is generated from it. Keep this local Obsidian working copy synchronized with `vault/` before publishing changes.
