# AGENTS.md as a Map

## Core idea and problem
Root instructions grow into stale encyclopedias that crowd out current constraints.

## How it works
Placement test: Root for global guidance; Route for conditional link; Check for deterministic assertion; Remove expired duplication. Critical does not always mean globally applicable.

## Example / failure mode
In an instructional scenario, a long root document retains old timezone advice and causes double conversion. No externally sourced incident or exact line count is established.

## Implementation and verification notes
Keep root short: system boundary, essential commands, global constraints, routes, completion command.
