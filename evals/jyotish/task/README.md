# Jyotish Coach core

Birth profiles, age and chart-grounded weekly coaching for a Vedic astrology coaching app.
Python 3.10+, standard library only, SQLite storage.

Run the tests: `python3 -m unittest discover -s tests -v`

Public functions other modules depend on (keep their names and signatures): `initialize`,
`save_profile`, `stored_profile`, `age_on`, `chart_for`, `compose_line`, `generate_coaching`,
`latest_coaching`. Keep the table and column names.
