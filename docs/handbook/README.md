# Harness Engineering Obsidian Vault

Open this folder as a vault and begin with [Harness Engineering - MOC](00%20-%20Start%20Here/Harness%20Engineering%20-%20MOC.md). Choose a route in [Learning Path](00%20-%20Start%20Here/Learning%20Path.md) or run [First Executable Harness Lab](11%20-%20Practical%20Implementations/First%20Executable%20Harness%20Lab.md).

This collection connects concepts, primary sources, synthetic failures, practical exercises and reusable templates. Reach, Power, Ground, Verdict and Carry are its organizing synthesis. Earlier shared-material attribution remains in [Source Coverage Index](00%20-%20Start%20Here/Source%20Coverage%20Index.md); new source-backed material is catalogued in [Source Register](00%20-%20Start%20Here/Source%20Register.md).

## Runnable learning

Python 3.10+ is enough for the included local lab:

```sh
cd Labs
python3 -m examples.booking.demo
```

No model credentials or package installation are required. The deliberately broken variant must fail two outcome checks before the fixed variant passes. See [Vault Update Record](00%20-%20Start%20Here/Vault%20Update%20Record.md) for verification and limitations.

## Public companion

[Harness-Engineering on GitHub](https://github.com/sakti1977/Harness-Engineering) provides the validator, tests, templates and the generated GitHub handbook. The learning content is maintained in its `vault/` directory; `docs/handbook/` is generated from it. Keep this local Obsidian working copy synchronized with `vault/` before publishing changes.
